# AsoCraft Studio Website

A responsive, single-page website for a fictional African-inspired fashion business. It was created as a student HTML, CSS and JavaScript project.

## Files
- `index.html` — page structure and content
- `styles.css` — external stylesheet, layout, Flexbox, Grid and responsive media queries
- `script.js` — mobile navigation, current year and contact-form validation

## How to run
1. Download and extract the project ZIP.
2. Open the `asocraft_studio_website` folder.
3. Open `index.html` in a web browser.
4. Internet access is needed for the Google Fonts and remote Unsplash photographs.

## Assignment requirements demonstrated
- Home, About, Products/Services and Contact sections
- Semantic HTML, headings, paragraphs, lists, links, images and form fields
- External CSS file
- Flexbox: navigation, values, footer and product information rows
- CSS Grid: About layout, product cards and contact layout
- Responsive media queries for mobile and desktop
- JavaScript variables, functions and event handling
- Contact form validation and user feedback
- README project documentation

## Important note about the contact form
The form validates the entered information in the browser. It does not send or store messages because no backend or form-submission service is connected. This matches the assignment's instruction not to pretend a demo form sends messages.
